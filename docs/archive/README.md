# Documentation Archive

This directory contains historical documentation that has been superseded by newer versions.

## Contents

Files in this archive are kept for reference but are **not actively maintained**.

### When to Archive

Move documentation here when:
- A feature has been completely redesigned
- Documentation becomes redundant with new structure
- Historical context is valuable but content is outdated

### Archive Naming Convention

- Original filename with date suffix: `FEATURE_STATUS_2025-12-15.md`
- Or organized by phase: `phases/phase-1-completion.md`
